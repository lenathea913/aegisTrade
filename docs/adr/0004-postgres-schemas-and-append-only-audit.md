# ADR 0004 — PostgreSQL schemas and a database-enforced append-only audit log

- **Status:** accepted
- **Date:** 2026-11-15

## Context

The journal must be trustworthy after the fact: if history can be edited, every
statement about past risk decisions is unverifiable. History also needs to survive
schema changes and remain querysable with plain SQL.

## Decision

1. **Three schemas** separate concerns: `market` (candles), `trading` (orders,
   trades, positions) and `audit` (`audit_logs`).
2. **`audit.audit_logs` is append-only at the database level.** The initial migration
   installs a trigger that raises on `UPDATE`, `DELETE` and `TRUNCATE`. Application
   code therefore cannot rewrite history even if it tries.
3. **Candles are idempotent by natural key** `(symbol, timeframe, open_time)` and
   inserted with `ON CONFLICT DO NOTHING`; a collector restart never duplicates a bar.
4. **Positions are upserted** (they are current state), while orders and trades are
   insert-only.
5. **Enum columns are `VARCHAR` + `CHECK`**, not native PostgreSQL enums: CHECK
   constraints are reversible migrations, whereas `ALTER TYPE ... ADD VALUE` has
   transactional restrictions and cannot be rolled back cleanly.
6. **Money is `NUMERIC(28,12)`, time is `timestamptz`** in UTC, and the initial
   migration is hand-written and reviewed rather than autogenerated blindly.

## Consequences

**Positive**

- The audit trail is immutable by construction, not by convention.
- Backtests, ledger rows and audit rows share one consistent numeric type.

**Negative**

- Correcting an erroneous row requires a new compensating event, not an update.
- If data must be purged (e.g. GDPR-style request), that is a deliberate superuser
  operation outside the application.

## Alternatives considered

- **Append-only in application code only.** Rejected: a single `session.execute` in a
  future script would silently break it.
- **Event sourcing with a separate event store.** Rejected as MVP scope: the ledger
  plus audit table already reconstructs decisions without a second system.
